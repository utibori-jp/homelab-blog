## はじめに

本記事は、e-Estonia連載の6本目である。

ここまでで、e-Estoniaとe-Japanそれぞれの概要や歴史を追ってきた。両国は同じ時期に電子政府を始めたにもかかわらず、いまはまったく違う場所にいる。今回はその2つの話を突き合わせ、両者で共通していた部分と異なる部分を整理したうえで、e-Japanが今後進む道について考えてみたい。

違いの理由としてよく聞くのは、エストニアは小国で、しかも独立回復直後で技術的負債が少なかったから、という説明だ。これは確かに大きい。人口が少なければ意思決定の階層も失敗のコストも小さく、e-Estonia編②で見た国際指標でも、上位に並んでいたのは小国ばかりだった。とはいえ、人口を減らすことも、積み上げてきた行政システムを一度捨てることも、日本にはできない。そこで、初期条件が有利だったことは認めたうえで、その後にそれぞれが何を選んだのかに目を向けたい。

先に断っておくと、どちらが優れているかという話をするつもりはない。「日本は○○だからデジタル化がうまくいっていないんだ」と言いたいわけでもない。日本のデジタル化をめぐる残念な話は探せばいくらでも出てくるが、今回はもう少し前向きな話がしたいと思っている。

## 何が同じで、何が違うのか

まず、両者のアーキテクチャの対応関係を一枚に整理しておく。細部はe-Estonia編・e-Japan編でそれぞれ触れた通りである。

| 役割 | e-Estonia | e-Japan |
| --- | --- | --- |
| 全国民のID | 個人識別コード | マイナンバー |
| 認証・電子署名 | デジタルID（PIN1/PIN2） | 公的個人認証（JPKI、利用者証明用/署名用） |
| 認証媒体 | IDカード／Mobile-ID・Smart-ID | マイナンバーカード／スマホ搭載電子証明書 |
| データ連携基盤 | X-Road | 情報提供ネットワークシステム |
| 各機関の接続点 | Security Server | 中間サーバ |
| ネットワーク前提 | 回線を問わない（インターネット可）＋相互TLS・署名 | LGWAN（閉域網） |
| 国民向けポータル | eesti.ee | マイナポータル |
| 運用・司令塔 | RIA（前身組織を含め1996年〜） | デジタル庁（2021年〜）／J-LIS／総務省 |
| データの保有主体 | 国の各機関（登録簿）が保有 | 自治体・各機関が保有 |
| IDの使い方 | 全システム共通の鍵として公開利用 | 連携には機関ごとの符号を使い、番号自体は使わない |
| 番号の民間利用 | 可 | 不可（法定の事務のみ） |
| 認証の民間利用 | 当初から | 2016年〜 |
| データ連携への民間参加 | 可（審査あり） | 不可 |

同じ役割を担う部品が、両国に揃っているのがわかる。それでいて、表の下半分の、番号をどう扱い、民間をどこまで入れるかという前提は正反対になっている。

### 同じ時期に、同じ問題を見ていた

電子署名の法整備とIDカードの配布は、順番も時期もよく似ている。

e-Estonia編①では「エストニアは、技術よりも先に法律を作った」と書いた。電子署名に手書き署名と同等の効力を与えるデジタル署名法が2000年、IDカードの配布開始が2002年である。一方の日本も、[電子署名法](https://laws.e-gov.go.jp/law/412AC0000000102)を同じ2000年に成立させ、2001年に施行したうえで、2003年から住基カードの交付を始めている。法律を先に整え、その2〜3年後にカードを配る。ここまでは、両国はほぼ横並びだった。

この時期、アメリカでは社会保障番号（SSN）が問題になっていた。本来は年金記録のための番号だったものが、銀行、保険、信用情報、大学、雇用主と用途を広げ、番号を知っていることが本人証明として通用する状態になった。その結果、なりすまし被害が社会問題化していた。日本もエストニアも、この事例を横目に見ながら制度を設計していたはずである。

しかし面白いことに、同じ前例を見ていたはずなのに、番号の扱いを定める法律は対照的なものになっていた。エストニアは個人識別コードを全システム共通の鍵として公開情報のように扱い、民間での利用を前提にした。一方の日本は、住基ネットの住民票コードでも、のちのマイナンバーでも、他人に番号を求めることも集めることも禁じ、法定の事務以外では使わせなかった。

## なぜ日本とエストニアで逆の法律ができたのか

### エストニア：民間が使えないと成り立たなかった

e-Estonia編①で見た通り、エストニアの行政は、機能するeIDを単独で作れる状態になかった。オンラインで顧客を識別する技術と、それに慣れた利用者を抱えていたのは銀行で、国は2000年のe-Taxで銀行の認証を借りてさえいる。IDカードの証明書を発行する認証局（SK）も、二大銀行と二大通信が共同で設立した会社だった。

エストニア政府にとって、銀行は協力してもらわなければeIDそのものが作れない、必要不可欠なアクターだった。だから、銀行が自分たちの業務でカードを使えるようにすることは、カードを成り立たせるための前提条件になった。

民間に開放する以上、番号を秘密にしておくことはできない。番号はIDとして公然と流通させ、安全性は認証と署名、アクセスログによる事後の検知といった、番号の外側で担保するしかなかった。

### 日本：民間に使わせなくても成り立った

一方の日本では、住基ネットで国が実現しようとしていたのは行政事務の効率化であり、民間に開放しなくても達成できる目標だった。e-Japan編②で見た通り、銀行は窓口での本人確認が確立していて、ネットバンキングの認証も自前で用意していたので、国の認証基盤を必要としていなかった。日本政府にとって、協力が不可欠な民間のアクターはどこにもいなかった。

しかしそれは、反対者がいなかったというわけではない。住基ネットには「国民総背番号制」という強い反発があり、各地で訴訟が起き、接続を拒む自治体まで現れた。杉並区のアンケートでは約8割が凍結か延期を求め、延期を求める意見書を採択した議会は70を超えた。SSNの前例がある以上、番号を民間に開放すれば同じ道を辿るという懸念には説得力があった。

このような状況を踏まえると、民間利用を禁止したことは仕方ないように見える。もともと使いたい民間はおらず、それで反対派を納得させて通せるなら、と考えても無理はない。こうして、利用範囲を法律で列挙し、罰則を置き、番号を知られても何もできない設計になった。

### ステークホルダーの要求が、そのまま法律になった

整理すると次のようになる。

| | エストニア | 日本 |
| --- | --- | --- |
| ステークホルダー | 銀行 | 反対する住民・自治体 |
| ステークホルダーの要求 | 自分たちの業務で使えること | 民間と結合させないこと |
| 番号の扱い | 公開して流通させる | 求めること・集めることを禁じ、法定の事務以外で使わせない |
| 安全性の担保 | 番号の外側（認証・署名・アクセスログ） | 番号の無力化（利用範囲の列挙・罰則・機関別符号） |

エストニア政府にとって民間の利用は前提条件で、日本政府にとっては、民間に利用させないことが必要条件だった。

住民基本台帳法は、民間の事業者が取引の相手に住民票コードを尋ねること自体を禁じている。

> 市町村長等以外の者は、何人も、その者が業として行う行為に関し、その者に対し売買、貸借、雇用その他の契約（以下この項において「契約」という。）の申込みをしようとする第三者若しくは申込みをする第三者又はその者と契約の締結をした第三者に対し、当該第三者又は当該第三者以外の者に係る住民票に記載された住民票コードを告知することを求めてはならない。
>
> ——[住民基本台帳法](https://laws.e-gov.go.jp/law/342AC0000000081) 第30条の38第2項

売買でも雇用でも、商売の相手に番号を聞いた時点で違反になる。民間と結合させないという反対派の要求が、ほぼそのままの形で条文になっている。

{{< admonition note "余談：番号は秘密なのか" true >}}
番号は秘密だと思われがちだが、法律は番号を秘密とは書いていない。書かれているのは、他人に番号を求めること、集めることの禁止である。実際、マイナンバーはカードの裏面に印字され、源泉徴収票にも載る。秘密にしなくても成り立つのは、番号を知られても単独では何もできず、集めてつなげることも禁じられているからだ。
{{< /admonition >}}

## カード配布後の現在地

### エストニア：カードがないと生活が回らなくなった

エストニアのIDカードは15歳以上に所持が義務付けられ、全員が持ったが、e-Estonia編①で見た通り、義務化しただけでは電子的に使われなかった。カードリーダーが必要で、使う先も少なく、使うメリットが特になかったからだ。

この状況を変えたのが、次の3点だった。銀行がIDカードをログイン手段として受け入れたこと、行政サービスが拡充されたこと、Mobile-ID・Smart-IDによってカードリーダーが要らなくなったことだった。

その結果、カード（およびスマホでの本人確認手段）がないと、日常生活のあちこちで困るようになった。

### 日本：あってもなくてもいいものに留まっている

住基カードは希望者への交付だったため、そもそも母数が作られず、普及率は5％程度で終わった。

マイナンバーカードは、マイナポイントという経済的インセンティブと、紙の保険証の廃止という不便化によって、母数を作ることには成功した。保有率は8割を超え、マイナ保険証の利用率も2026年1月時点で64.62％まで来ている。

数字だけを見れば、使われている。でも、ここで問うべきは利用率ではないと思う。国民からすれば、紙の保険証が使えなくなったからマイナ保険証を使っているだけであって、どちらでもよかった。さらにいえば、カードがなくても資格確認書があれば、マイナンバーなしでも医療機関にはかかれる。これは置き換えであって、新しくできるようになったことではない。

もっとも、置き換えという点では、エストニアの銀行ログインも同じだ。国民からすれば、ログインできるなら従来の方法でもIDカードでもよかったはずである。ただ、エストニアではその先があった。銀行に続いて、行政サービスや契約の署名、処方箋の受け取りまで同じカードで済むようになり、カードを持っていないと、あらゆる場面で不便になった。カードを使う場面が少しずつ増えていったことで、最終的にカードがなくてはならないものになった。そう考えると、日本でもマイナンバーをなくてはならないものにするためには、民間を巻き込む必要があるのではないか。

### 民間の入り口はすでに開いている

民間を巻き込むといっても、ここまで見てきた通り、日本は番号の民間利用を法律で禁じてきた。これでは民間の出る幕がないように見える。しかし実は、法律が禁じたのは番号を求めたり集めたりすることで、カードで本人確認をすることまでは禁じていない。e-Japan編①で触れた通り、公的個人認証（JPKI）は2016年に民間へ開放されており、制度上は民間サービスの認証手段としてマイナンバーカードを使える。エストニアが銀行から始めた経路は、日本でも法律上はすでに開いている。

総務省によれば、公的個人認証を使う民間事業者は2026年8月時点で1,306社にのぼる。ただ一覧を見ると、使い道のほとんどは口座開設時の本人確認だ。エストニアの銀行がIDカードを毎日のログインに使ったのに対し、日本では最初の一回だけしか使われない。

日常の認証にまでマイナンバーカードを使う民間は、まだ目立たない。各事業に事情はあるだろうが、筆者なりに理由を考えてみた。

{{< admonition note "なぜ民間はJPKIを採用しないのか（筆者の推測）" true >}}
民間でのJPKIの普及が進まない主な理由は以下の3つではないかと考えている。

1. eKYCの方が枯れている：民間では、身分証の画像と顔を突き合わせるeKYCがすでに広く普及しており、実装経験のあるエンジニアやナレッジにもアクセスしやすい。カードやアプリを前提にした認証は組み込みのコストが大きく、事例も少ないうえ、すでに動いているeKYCを置き換えても上積みが見えにくい。
2. 仕様が変わり続けること：スマホへの電子証明書の搭載や、e-Japan編②で触れた2029年度の次期カードへの切り替えなど、仕様の変更が続いている。
3. 併設の手間：カードの取得は義務ではないため、カード認証だけでは全顧客をカバーできず、他の認証手段も併設しなければならない場合がある。

個人的には、技術選定の場面では、eKYCという選択肢がある時点でまずそちらが選ばれるように思う。認証は多くの企業にとってコアドメインではなく、そのうえ障害や不具合が起きたときの影響が大きいとなれば、枯れていて普及している技術がまず選ばれるだろう。
{{< /admonition >}}

## 国民の信頼で普及の差は説明できるか

ここまで、普及の差を実利と民間の利用から見てきた。一方で、e-Estoniaの成功要因を調べていると、まったく別の説明もよく目にする。「政府の透明性が高く、国民の信頼を得たから成功した」というものだ。障害が起きたときにきちんと情報を公開して対応しているから信頼につながった、という筋書きだ。だが、これで普及の差を説明するのは難しい。

住基カードとマイナンバーカードは、やろうとしたことがほぼ同じだった。それでも普及率は約5％と8割超に分かれた。間の十数年で国民の信頼が劇的に変わったと考えるより、マイナポイントという実利と、保険証廃止という不便化が大きかったと考える方が自然だ。エストニアでも、銀行で使えるようになり行政サービスが拡充されるまでは、持っているが使われない状態が続いた。

また、政府の透明性という観点でも、日本とエストニアのデジタル化の差を説明できるほどの違いはない。政府の清廉さや制度の健全さを示す指標でランキングを比べると、確かにエストニアは上位にいるが、日本も決して悪い順位ではない。

| 指標 | エストニア | 日本 |
| --- | --- | --- |
| [腐敗認識指数（CPI）](https://www.transparency.org/en/cpi/2024) | 12位 | 18位 |
| [WJP法の支配指数](https://worldjusticeproject.org/rule-of-law-index/global/2024) | 10位 | 14位 |

加えて、エストニアも全ての情報を正確に開示してきたわけではない。e-Estonia編②で見た通り、エストニアはRIAが毎月インシデントを公開している一方で、PINなしで使えるIDカードが見つかった際には9か月後に「心配する理由はない」と告知し、同じ秘密鍵が入ったカードの問題は原因がはっきりするまでに5年かかっている。日本も障害を隠しているわけではなく、むしろ昨今のニュースを見ていると、情報流出の事実を潔いほど公表している。

そもそも、信頼が普及を左右するなら、障害が起きるたびに利用は落ちるはずだ。ところが、筆者がエストニア滞在中に話を聞いた範囲では、いずれも「小さな障害は日常的に起きているし、不満も少なからずあるが、実利を手放すほどではないから使い続けている」といった反応だった。信頼というよりは、シンプルに実利での判断をしているように感じた。

日本でも、目立つ事故は住基カードよりもマイナンバーカードの方が多い。2023年には紐づけ誤りやコンビニでの証明書の誤交付が相次いだが、それでも普及は止まらなかった。もちろん、手数料や使い道の少なさなど住基カード側の事情もあり、差のすべてを実利と不便化で説明できるわけではない。少なくとも、事故が増えても使われ続けているという点では、エストニアで聞いた話と変わらない。

これは決して国民からの信頼が無意味だと言いたいわけではない。デジタル化に限らず、どんな政府の取り組みであっても、国民からの信頼なしに進められることはない。ただ、デジタル化という文脈においては、国民からの信頼や政府の透明性というよりは、使う理由や実利が重要なのではないか。

## 日本に必要なのは、マイナンバーカードを必要とする民間

では、民間に使ってもらうにはどうすればいいのか。エストニアの銀行は、認証局を共同で作った当事者として、自分たちが使いやすい形を制度に求めた。日本に必要なのも、マイナンバーカードなしでは業務が成り立たない民間のアクターではないか。

その兆しはすでにある。e-Japan編②で触れた通り、偽造カードによるなりすましを受けて、対面の本人確認ではICチップの読み取りが原則義務化される。非対面でも、ディープフェイクによるeKYCの突破が問題化し、マイナンバーカードによる認証へ寄せる方向で法規制が進んでいる。きっかけは規制だが、銀行や携帯キャリアは、日本で初めて「マイナンバーカードがないと本人確認が回らない」当事者になりつつある。

この流れをただのeKYCの代わりで終わらせないためには、民間が日常の認証にも自分から使いたくなる仕組みである必要がある。民間の事業者が採用を判断するときに見るのは、要件が明確で、余計なリスクや管理義務を負わされず、仕様がころころ変わらず、止まらないことだ。

突き詰めれば、どれも事業者がこの基盤を信頼できるかどうかという話ではないか。そしてその信頼を得るために、彼らをエストニアの銀行のように設計の当事者として扱い、民間が使いやすい形に制度を整えていくことが大事だと思う。マイナンバーカードが民間から信頼される認証基盤になったとき、日常で使う場面が増え、「あってもなくてもいいもの」から「なくてはならないもの」になれるはずだ。

## さいごに

エストニアと日本の20年を並べてみて、筆者は、初期条件を除けば差を生んだのは政府の制度設計だったと思っている。エストニアは銀行の協力なしにはカードを作れなかったので、最初から民間が使える形にした。日本は民間の協力を必要としなかったので、反対派を納得させる形にした。カードを使う理由が生まれるかどうかは、この時点でほぼ決まっていた。エストニアではカードがないと生活が回らなくなり、日本のカードはいまも「あってもなくてもいいもの」に留まっている。

日本のカードを生活の一部にするには、民間に使ってもらうしかない。そのためには、事業者が安心して本人確認を預けられるくらい、制度が整っている必要がある。

課題も残っている。カードの読み取りや暗証番号の手間はまだあるし、eKYCから乗り換える理由も弱い。一方で、追い風もある。保険証の一本化で国民との接点ができ、本人確認の規制強化で、銀行や携帯キャリアはマイナンバーカードを使う方向に動き始めている。

人口や行政の歴史は変えられないが、制度設計なら日本でも変えられる。歴史で見れば、マイナンバーカードはいま、日本の国民IDとして過去で一番うまくいっている。住基カードは5％程度で終わったが、マイナンバーカードは8割を超える人が持ち、民間でも1,300社を超える事業者が使い始めている。

正直、連載を始める前は日本のデジタル化に悲観的で、なぜこんなにもうまくいかないのかと思っていた。しかしこうしてうまくいっている国と比較してみると、与えられた制約条件の中で、むしろ良くやっているのだなと見方が変わってきた。依然として問題は多いが、少しずつ良い方に向かっていると、一人のエンジニアとして、未来に期待したい。

制度の話はここまでである。次回はおまけとして、2か月間エストニアを歩いて見たもの、感じたものを、肩の力を抜いて書いてみたい。
